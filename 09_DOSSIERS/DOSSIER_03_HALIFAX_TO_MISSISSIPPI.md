# DOSSIER 03 — HALIFAX TO THE DEEP SOUTH
## John Partin, Barnabas Partin and the migration corridor

### Halifax John
Earlier project compilation identifies a strong record trail for a John Partin in the Halifax/Edgecombe environment:
- 1762 tax evidence.
- 1772 Edgecombe deed involving Elias Fort.
- 1774 Halifax road appointment.
- 1782 tax evidence.
- 1795 Halifax will naming Mary, Robert, Charles, Barnabas and David.

These records should be treated as a coherent research cluster while each original citation is recovered.

### Why the 1795 will matters
A will naming the children/household provides a documentary anchor for the next generation. It can constrain competing theories about John's identity and the placement of Barnabas far more effectively than unsourced trees.

### Barnabas
Current reconstruction uses a 1773 birth year for Barnabas. The repository must attach the source for that date and then trace him event by event through the Carolinas and into the Mississippi-associated descendant line.

### FAN network
High-value associated surnames preserved from prior work include Fort, Tucker, Reeves, Rawlings, Lee, Moore, Chatham and others. These names should be mapped by event, not merely listed. Repeated co-occurrence across county/state transitions can help identify migration.

### Migration method
For each move:
1. establish last proven event in origin county;
2. establish first proven event in destination;
3. compare associates and neighbors;
4. compare land and waterways/roads;
5. compare names/ages and household structure;
6. search probate/deeds for explicit former residence;
7. use DNA only as corroboration.

### Current assessment
The Halifax household is substantially more documentable than the bridge connecting it backward to Surry/Sussex. Barnabas's downstream line is a separate proof problem and will receive its own generation-by-generation dossier.
