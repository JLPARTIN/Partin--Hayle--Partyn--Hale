# 1637 Robert Partin Lease — Recovery Target

A digitized index in *Virginia County Records*, volume 6, includes an entry:

**Robert Partin (lease) — 1637 — 40 [acres] — page 503.**

This is an important intermediate target between the 1620s household and the 1655 Senior/Junior land reference.
