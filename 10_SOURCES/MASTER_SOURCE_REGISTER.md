# Master Source Register

This register catalogs the project's highest-value sources by type, per the source hierarchy in `README.md` and `EVIDENCE_STANDARD.md`. It supplements, rather than replaces, `SOURCE_REGISTER.md` and the bundle-specific registers already in this directory. See `00_PROJECT_CONTROL/RECOVERED_RESEARCH_INVENTORY.md` for the full catalog of the September 2026 Google Drive recovery.

## Sourcing rule for this register

An entry moves from "Compiled genealogy" to "Original/near-original" tier in this register only once this project has independently obtained and reviewed the underlying image or an authoritative printed edition — not merely because a recovered AI-research document states a specific archival citation. Every citation above should therefore currently be read as "a specific, checkable lead," not as "verified."
