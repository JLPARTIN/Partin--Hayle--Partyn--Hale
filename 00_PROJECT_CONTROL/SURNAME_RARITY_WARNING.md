# Methodological Warning — Partin Surname Rarity

The project previously benefited from the apparent rarity of Partin/Partyn, but rarity cannot be treated as uniqueness.

Virginia patent/headright material reports several Partin-type names between 1662 and 1683 outside the core Robert Sr./Jr. evidence.

## Rule
Never argue:
“same rare surname in Virginia = same paternal family.”

Instead require some combination of:
- explicit kinship;
- continuous land/title chain;
- chronological continuity;
- distinctive FAN network;
- probate;
- repeated neighborhood;
- Y-DNA tied to documented descendant lines.

This warning is especially important for the unresolved 1655→1700 bridge.
