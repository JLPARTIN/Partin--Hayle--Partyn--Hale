# Critical Contradiction — Did the 1795 Halifax Will Name a Son John?

## Version A
Several recovered research notes and the 1997 Jim Partin query list the elder John's children as Robert, Brasel, Barnabas, David, Charles, Lucy, Sarah, Mary, Priscilla and Elizabeth — **no John**.

## Version B
Other recovered repository summaries state that the will named/devisees included **John, Barnabas/Barnaby, William and others**, and use this to support John B as Barnabas's brother.

## Why this matters
This single reading directly affects the parentage trial for John B.

## Rule
No conclusion may rely on either version until the original will/probate image is re-read line by line.

## Extraction protocol
Transcribe:
- every named child/devisee;
- every relationship word;
- every tract/bequest;
- wife;
- executors;
- witnesses;
- signature/mark;
- probate date;
- any marginal continuation.
