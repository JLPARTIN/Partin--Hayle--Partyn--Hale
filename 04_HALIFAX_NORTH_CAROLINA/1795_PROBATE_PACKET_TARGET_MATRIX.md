# John Partin 1795 Probate — Packet Target Matrix

Do not search only for a will book.

| Record | What it can prove |
|---|---|
| will | beneficiaries and relationship language |
| probate order | date, witnesses, executor qualification |
| executor bond | associates/securities |
| inventory | household/economic context |
| estate sale | children, in-laws, neighbors |
| account current | debts and distributions |
| final settlement | heirs and shares |
| guardian bonds | minor children |
| land division | inherited tracts and adjacency |

## Critical surnames to flag
Hux/Hucks, Fort, Rawlings, Tucker, Reeves, Lee, Moore, Chatham, Partin variants.

The packet can be more genealogically valuable than the will alone.
