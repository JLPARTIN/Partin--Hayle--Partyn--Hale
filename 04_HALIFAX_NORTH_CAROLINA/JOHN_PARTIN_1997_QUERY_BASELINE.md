# John Partin — 1997 Query Baseline

The December 1997 NCGenWeb query by Jim Partin is useful because it distinguishes what that researcher believed from what he was still seeking.

## Reported
- John b. ca 1722;
- d. Jul 1795 Halifax;
- wife Mary b. ca 1740, d. ca 1805;
- children Robert, Brasel, Barnabas, David, Charles, Lucy, Sarah, Mary, Priscilla, Elizabeth;
- 100 acres adjoining Great Darlling Swamp purchased from William and Ann Hux on 11 Aug 1767.

## Explicitly unknown / requested
- John's parents;
- exact birth date;
- birth place;
- marriage date;
- Mary's maiden name.

## Methodological value
Any modern tree supplying those missing facts must produce evidence later than—or independent of—the 1997 reconstruction. The query cannot be cited as support for them.
