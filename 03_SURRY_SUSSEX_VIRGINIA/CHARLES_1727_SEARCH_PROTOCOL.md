# Charles Partin 1727 — Search Protocol

The phrase “late in the tenure of John Rawlings” is still only a derivative lead.

## Search all variants
Charles Partin / Parton / Parten / Partain.

## Capture
- grantor/grantee;
- exact date;
- book/page;
- acreage;
- parish/residence;
- consideration;
- source-of-title recital;
- complete bounds;
- wife/dower;
- witnesses;
- acknowledgment.

## Adjudication question
Does Charles's land actually descend from the same 1692 Rawlings patent as Robert's 1706 tract, or is “John Rawlings” merely a prior tenant/neighbor on a different tract?

Do not use the derivative webpage's phrase “that land” as parcel proof.
