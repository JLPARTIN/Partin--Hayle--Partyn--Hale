# 1727 Robert Partin → John Justice / Elizabeth Dower Trial

## Existing compiled sequence
The working archive places two linked events in 1727:
- March: Robert Partin sells 200 acres to John Justice.
- June: Elizabeth relinquishes dower.

## Central test
Was the 200-acre tract the same 200 acres John Rawlings conveyed to Robert in 1706?

If yes, and if the dower entry explicitly identifies Elizabeth as Robert's wife, then the evidence chain becomes:
John Rawlings → daughter Eliza. Partin → Rawlings land to Robert → Robert sells same land → wife Elizabeth releases dower.

That would be powerful indirect proof that Eliza. Partin was Robert's wife.

## Required comparison
Transcribe metes/bounds, acreage, parish, neighbors, consideration and recordation from both the 1706 and 1727 deeds. “200 acres” alone is insufficient.
