# Y-DNA Framework

## Rule
Y-DNA can establish or strongly support patrilineal relatedness and branch order. It cannot by itself name the historical man in whom a mutation arose.

## Current project observations
Research has referenced a Parton/Partin/Partain FTDNA cluster and a node reported as R-FTF47086. Recent observations report restructuring beneath FTT183 / FTT184 / FTT185 while Halifax and Sussex remained separate.

Because FTDNA topology and age estimates change, every capture must include retrieval date, terminal SNP, upstream/downstream nodes, tester's documented endpoint, test type, and age-estimate confidence interval.

## Working branch hypothesis
If several documented branches merge beneath a downstream SNP while Halifax and Sussex remain outside it, Halifax and Sussex may represent earlier-diverging paternal branches. That pattern is potentially important for locating the split nearer the older Virginia generations, but it does not identify a particular colonial father without documentary evidence.

## Key test
Determine the immediate common upstream node of Halifax, Sussex and the newly merged branches, then compare its age interval with the documentary chronology. The documentary tree and genetic tree should be developed independently before correlation.
