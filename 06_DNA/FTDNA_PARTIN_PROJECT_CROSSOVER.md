# FTDNA Project Crossover Finding

The Barnabas-linked Partin Big Y result surfaced on a public **Vann** project page rather than a Partin-specific page.

## Why this matters
Relevant Partin kits may be enrolled in surname, geographic or haplogroup projects outside the expected Partin project. Restricting searches to a single surname project can miss useful public results.

## New search protocol
Search FTDNA public pages for:
- Partin / Parton / Partain / Parten;
- known kit IDs;
- R-FTF47086 and upstream SNPs;
- collateral project memberships.

Then reconcile the same kit across projects before counting it as an independent tester.
